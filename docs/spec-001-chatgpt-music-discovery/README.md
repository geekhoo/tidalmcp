# ChatGPT music discovery with TIDAL

Use the existing TIDAL MCP and MCP Apps component to help people explore from music they like, optionally draw on a bounded sample of their own saved music, and discover further artists and releases through ChatGPT. The proposed first release is read-only and returns people to TIDAL to listen.

**Status:** Spec written — not yet planned or implemented. Live AI use is gated on TIDAL permission; public listing eligibility is unresolved.

**Spec:** [feature-specification.md](feature-specification.md)

**Research:** [research.md](research.md), reviewed 1 October 2026 (Asia/Singapore).

**Next:** Resolve the permission gates, then `/geeky-plan docs/spec-001-chatgpt-music-discovery/`. Planning must preserve any unresolved release blockers. No planning package or frozen contract was created by this research.

TIDAL's published developer rules restrict AI use of its content, with express written approval described in its developer guidelines. Personal account consent is a separate requirement. OpenAI's current public-directory rules also restrict offerings that primarily function as unofficial third-party connectors. These are substantive eligibility gates, not missing SDK features.
